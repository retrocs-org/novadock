NovaDock catalogs
=================

novadock.cd   Catalog descriptor (generated by tools/generate_catalog.py from
              src/novadock.c; do not edit by hand).
svenska.ct    Swedish translation (ISO-8859-1).
deutsch.ct    German translation (ISO-8859-1).

Build a catalog with FlexCat (Aminet: dev/misc/FlexCat.lha):

  FlexCat catalogs/novadock.cd catalogs/svenska.ct CATALOG LOCALE:Catalogs/svenska/novadock.catalog

or with CatComp:

  CatComp catalogs/novadock.cd catalogs/svenska.ct CATALOG LOCALE:Catalogs/svenska/novadock.catalog

NovaDock opens the catalog through locale.library (OS 2.1+) and falls back to
its built-in English for missing strings. Keep printf conversions (%s, %d,
%.31s) in the same order; NovaDock ignores a translated format whose
conversions differ or that is longer than 80 characters.

Plurals: some English messages add an "s" through a %s conversion, for example
"Started %d archive%s; %d rejected". A language that does not form plurals
that way keeps the conversion but prints nothing with %.0s:

  Startade %d arkiv%.0s; %d avvisade

FlexCat reports such a line as a "mismatching placeholders" warning; that is
expected, and the catalog is still built correctly.

Message IDs stay stable when new dock messages are added, so existing
translations keep working; untranslated new strings fall back to English.

To start a new language, create a translation file:

  FlexCat catalogs/novadock.cd NEWCTFILE catalogs/<language>.ct

Only the dock's own messages, menus and calendar are translated in 0.1; the
Preferences application is still English-only.

Release builds compile every translation automatically when FLEXCAT points to
FlexCat (scripts/build-and-stage-amiga.sh), and Install-NovaDock installs
them as LOCALE:Catalogs/<language>/novadock.catalog.
