# AQUARIUM plugin

Add **AQUARIUM** from Add item > Plugins for an animated fish tank. Click its
tile for a fullscreen aquarium with swimming fish, plants and rising bubbles.
Any key or mouse click closes it. The opening click's release is ignored.

Edit settings selects one to eight fish, bubbles and Slow/Normal/Fast animation.
Use applies settings for the session; Save keeps them after restart.
The fullscreen scene keeps its proportions, reuses one bitmap, pauses when
another window is active and closes when NovaDock exits. The dock animation
slows when hidden. No network connection, external player or sound is used.
