# Roadshow connections

Roadshow connection controls are provided by the [Network plugin](NETWORK_PLUGIN.md).
The standalone Roadshow plugin and executable alias are no longer included.
Existing Roadshow tiles migrate to Network when settings are loaded. Legacy
option values remain available as a fallback; updates keep user settings.

The update installer removes the retired program, icon and manifest. For a
manual update, quit NovaDock first, remove those old Roadshow files from the
Plugins drawer, install the new binaries and restart the dock.
