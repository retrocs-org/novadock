HASS artwork bank

For the NovaDock HASS plugin 0.1 and NovaDock 0.4 or later.
Keep Artwork.ndart beside HASS as HASS.assets/Artwork.ndart.
Update it with the plugin and restart or reload NovaDock afterward.

Artwork: NovaDock contributors, MIT licence (see the project LICENSE).
Authoring sources: plugin_src/hass/artwork/ in the source tree.
Format and SDK: docs/PLUGIN_SDK_ARTWORK.md.
